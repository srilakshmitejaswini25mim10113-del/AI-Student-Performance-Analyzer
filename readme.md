# AI Student Performance Analyzer

## Overview

AI Student Performance Analyzer is a Python-based project designed
to analyze student academic performance.

The system accepts student information such as attendance,
assignment marks, internal marks, and study hours. It analyzes
the information and generates a performance level and prediction.

## Features

- Student details input
- Performance analysis
- Average marks calculation
- Performance prediction
- Final performance report

## Technologies Used

- Python
- Visual Studio Code
- Git
- GitHub

## Project Modules

1. Student Details Module
2. Performance Analysis Module
3. Prediction Module
4. Report Generation Module

## Project Structure

- main.py - Main program
- student_details.py - Collects student information
- performance_analysis.py - Analyzes academic performance
- prediction.py - Predicts performance
- report.py - Generates the final report
- utils.py - Contains utility functions
- requirements.txt - Project requirements
- statement.md - Project statement

## How to Run

1. Install Python.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

python main.py

5. Enter the student details when prompted.
6. View the generated performance report.
