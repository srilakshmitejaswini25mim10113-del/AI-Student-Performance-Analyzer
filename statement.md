# Problem Statement

## Project Title
AI Student Performance Analyzer

## Problem Statement

Students' academic performance depends on several factors such as
attendance, assignment marks, internal marks, and study hours.
Manually analyzing these factors can be time-consuming.

The AI Student Performance Analyzer is developed to analyze student
academic information and provide a performance level and prediction.
The system accepts student details, processes the academic information,
and generates a student performance report.

## Scope of the Project

The project focuses on analyzing basic academic information provided
by the student. It calculates average marks, determines the performance
level, and provides a performance prediction based on predefined rules.

## Target Users

- Students
- Teachers
- Academic mentors

## High-Level Features

1. Student details input
2. Academic performance analysis
3. Performance prediction
4. Student performance report generation
